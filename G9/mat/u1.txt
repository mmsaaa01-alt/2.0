Unit 1: Further on Sets

    This unit builds upon basic set concepts learned in Grade 7, introducing more advanced definitions, operations, and applications of sets. The concept of a set is fundamental in modern mathematics and is used to define relations and functions.

1.1 Sets and Elements
Defining a Set

A set is a collection of well-defined objects or elements.

    Well-defined: This means that for any given object, we can definitively determine whether it belongs to the set or not.

Examples of Well-Defined vs. Not Well-Defined Sets:

    Well-defined:
        Collection of students in your class. (Elements are clearly known).
        Collection of consonants of the English alphabet. (Clearly defined members).
        A collection of all boys in your class.
        A collection of all natural numbers less than 100.
        The collection of songs by Artist Tilahun Ges sese.
    Not well-defined:
        Collection of beautiful girls in your class. (What constitutes "beautiful" is subjective).
        Collection of hardworking teachers in a school. (What constitutes "hardworking" is subjective).
        The collection of kind students in your school. (Subjective criteria).

Elements of a Set and Notation

    If a is an element of set A, we say " a belongs to A ". The Greek symbol ∈ (epsilon) denotes "belongs to". We write this as a ∈ A.
    If b is not an element of set A, we write b ∉ A and read it as " b does not belong to set A " or " b is not a member of set A ".

Examples of Element Notation:

    Consider G as a set of vowel letters in the English alphabet. Then a ∈ G, o ∈ G, i ∈ G, but b ∉ G.

Conventions for Naming Sets and Elements

    Sets are usually denoted by capital letters like A, B, C, X, Y, Z, etc.
    The elements of a set are represented by small letters like a, b, c, x, y, z, etc.

1.2 Set Description

Sets can be described in various ways to clearly communicate their elements.
i) Verbal Method (Statement Form)

    In this method, the well-defined description of the elements of the set is written in an ordinary English language statement form (in words).

Examples of Verbal Method:

    The set of whole numbers greater than 1 and less than 20.
    The set of students in this mathematics class.

    In this method, all elements of the set are completely listed.
